## 2. Design Decisions Summary (Report Mapping)

- **User-Centered Design & Accessibility ([`RUBRIC.md`](../../RUBRIC.md) Section I & III):** Family reviews guided the move away from decorative dark/futuristic boxes toward high-contrast flat cards, looped Thai sans-serif typography (`K2D`), accidental-tap safeguards (Sign-Out confirmation modal), and simpler filtering/sorting.
- **Personalization & Scope Trade-offs:** Family feedback drove a clear architectural change—moving LINE notification pairing from owner-only to per-user member access so each household member can track favorite items and categories—while deferring an optional LLM recipe/menu-suggestion chatbot to protect core embedded implementation and testing time.
- **Sensor Correlation UX:** Combining Temperature, VOC, and Light onto a single toggleable timeline with aligned limit lines and door-event tags addresses root-cause diagnosis (e.g., linking door openings to temperature/VOC spikes) without forcing elderly users to read multi-chart telemetry.
- **Prototyping & Design Tooling ([`RUBRIC.md`](../../RUBRIC.md) Section 4.6):** Initial interactive flows were prototyped using Claude Artifacts as standalone HTML/CSS/vanilla JS before migrating to the production React + TypeScript implementation and Figma design system.
