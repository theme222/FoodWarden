description: Derive jobs from real workflows and simplify UI into a small set of reusable primitives with contextual controls.
---

# Workflow

- Write each job as “When this happens, I want to do this, so I can achieve this.” Trace it to a real route or state.
- Show actions at the point of need, such as selection controls after selection or Retry beside the failing section. Favor a nearby action over an extra page or popup.
- Compose approximately five to seven existing primitives before introducing new ones. Define the purpose, variants, phone layout, text wrapping and keyboard contract.
- Remove redundant entry points and repeated status chrome. Verify that the remaining entry point is discoverable on touch and with a keyboard.
