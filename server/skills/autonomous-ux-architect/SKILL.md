name: autonomous-ux-architect
description: Redesign difficult existing product workflows from code and observed use. Derive improvements and a file-level plan from the product itself.
---

# Workflow

1. Trace actual routes, API calls and rendered states. Identify click depth, dead ends, duplicate data entry, overloaded screens and missing feedback.
2. Propose low-effort fixes, higher-impact changes supported by existing data, and controls or steps to remove for each. Derive sensible defaults from deterministic rules and label estimates.
3. Describe the shortest route, high-risk path and information hierarchy. Give each screen one clear primary task when appropriate. Include the state matrix and define keyboard, focus, confirmation, and retry behavior.
4. Reuse existing primitives and design tokens. Consolidate duplicate rendering only where the behaviors really match.
5. List the changes by file with observable acceptance criteria. Stop for confirmation when the request is planning-only. When implementation is requested, validate each batch against the real routes.
